## 一、从“空间怎么包裹镜头”出发（六大平等空间骨架）

构思画面时，**先决定三维空间骨架，再往里面放锚点物件**，而不是先想一个物件再垫一块方形地板：

| 骨架编号 | 空间拓扑类型 | 镜头与空间关系 | 对应模板积木 (`templates/spatial_archetypes.py`) |
| :--- | :--- | :--- | :--- |
| **① 室内包裹** | 封闭大厅 / 阈限走廊 / 池核水厅 | 相机在房间里面，头顶有吊顶或格栅天窗，透过门窗洞看到隔壁亮区 | `build_enclosed_room` (`spatial_mode="interior"`) |
| **② 垂直深井** | 多层天井 / 层叠楼梯间 / 电梯井 | 纵向 3~5 层回廊栏杆上下叠落，高处一束光斜切到底部暗处 | `build_vertical_atrium` + `create_volumetric_light_beam` (`spatial_mode="interior"`) |
| **③ 两侧夹峙** | 建筑峡谷 / 粗野柱廊 / 窄巷高塔 | 左右两排高墙或巨柱把视线夹向深处，低角度仰望尽头尖塔或窄缝天光 | `build_canyon_corridor` (`spatial_mode="grounded"`) |
| **④ 失重与非欧** | 悬空虚景 / 倒置重力 / 视错觉闭环 | 没有地面；器物倒悬、旋梯悬空、巨环横穿云层，或四面墙各有上下重力、彭罗斯死循环阶梯 | `build_spiral_stair_ribbon` / `build_orbital_ribbons` / `build_gravity_flip_room` / `build_impossible_stair_loop` (`spatial_mode="floating"`) |
| **⑤ 前景框景** | 窗台近景 / 帘幕遮挡 / 门缝窥视 | 半透明轻纱或窗框贴在镜头前做柔焦遮挡，中景窗台放小器皿，窗外极简海天 | `build_window_frame_stage` (`spatial_mode="framed"`) |
| **⑥ 开阔地景** | 水岸埠头 / 盐滩荒原 / 低模山谷 | 仅占六分之一权重；地面必须用大半径圆盘且远山底座深埋地下，绝不露方形地毯边 | `build_endless_ground` + `build_grounded_backdrop_ridge` (`spatial_mode="grounded"`) |

## 二、跨流派发散维度（现场随机抽组，严禁照抄原词）

结合 `python scripts/profile_manager.py --hints` 返回的 `divergent_suggestions`，用下面三个正交轴现场碰撞出全新画面：

### 轴 A：非常规法则扭转（打破日常习惯）
- **尺度反转**：极其微小的日常物品旁立着几十米高的混凝土肋墙或天顶巨环。
- **重力失效**：大型器物（乐器、书架、电话亭、石柱）斜悬在半空，花瓣或镜面碎片定格在四周。
- **空间错位**：天花板和左右墙壁上也长出正常带栏杆的楼梯与门洞；或正交视角下首尾咬合的死循环台阶。
- **无人过渡感（阈限）**：本该热闹却空无一人的干净瓷砖水池厅、弧形前台、发光自动门或黄色防滑立牌。

### 轴 B：视觉焦点物件（至少拆 3 个真实结构部件）
- 室内/阈限类：弧形导台与立柱、带扶手的不锈钢泳池梯、发光自动售货机、推车与警示牌。
- 垂直/巨构类：多层铁艺雕花栏杆、街灯柱与石阶、层叠尖顶高塔、横跨两侧高墙的连桥。
- 超现实/框景类：倒悬三角琴、倾斜巨剑剪影与碎镜片、透光渐变水杯与小花、悬空双环。

### 轴 C：光与空气行为（不用“斜阳拉出长影”套话）
- 顶角有界体积光柱（亮雾斜切暗厅）、嵌入式顶棚发光灯带、门洞外强曝光漫射白光、阴天湿砖镜面反光、半透纱帘逆光光晕。

## 三、双模式输出语感对照（仅看说话松紧度，严禁照抄字词）

注意：无论哪种模式，句子都要顺畅自然，**严禁用逗号、顿号或斜杠把一句话切成密集的四字词碎片**。

- **简易模式写法（孩童聊天式直白口语，零术语）**：
  - `干净空荡的白蓝水池大厅`
  - `倒着飘在云里的大钢琴`
  - `四面墙都长着楼梯的怪房间`
  - `飘着薄纱窗帘的海边窗台`
- **详细模式写法（顺畅平实的自然句子 + 单个核心括号说明，拒绝斜杠参数堆砌）**：
  - `空无一人的白蓝弧形接待大厅，顶棚格栅透下柔光（阈限室内广角）`
  - `大钢琴倒着悬在深色云层里，旁边绕着无支撑的旋转楼梯（超现实失重构图）`
  - `四面墙和天花板上各自长出带栏杆的楼梯，打破上下重力（非欧多重力空间）`
  - `两边是高耸的裸露水泥墙，从窄巷底下仰望尽头的尖塔（粗野主义广角仰拍）`
