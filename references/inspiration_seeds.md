# 空间构思与发散参考（多元平等、去套路化）

> **核心原则**：
> 1. **禁止照抄原词与固定句式**：下文仅展示跨维度构思的逻辑骨架，实际向用户提问时必须结合当前对话语境现场改写，不要套用“地点+物体+斜阳拉出长影”的散文公式。
> 2. **用户意象优先于随机发散**：一旦用户自己给出了场景想法、氛围词或文化意象（不论是某种未来乌托邦想象、日常怀旧片段还是诗意情绪），**必须先解码该意象自带的时代美学与情绪基调并向用户确认**，严禁用无关的随机种子或旧模板套路强行覆盖用户的意图！
> 3. **广谱均衡**：仅在用户还没想好、主动要求提供灵感时，才从下方多元空间骨架中跨流派均衡抽样，不让任何单一画风霸榜。

## 二、主题意象语义转译三步法（当用户给出诗意/文化概念时）

当用户输入一个偏抽象、诗意或带有文化指代的主题（而非具体物件清单）时，**先做以下三步语义解码**，再给出 3~4 个契合该主题但审美落点各异的具体构想供用户拍板：

1. **时代与亚文化审美识别**：这个命题在视觉文化中通常指向哪些流派或时代气息？（例如：静谧怀旧日常 $\to$ 日式清透窗景 / 东方木构庭院 / 极简光影建筑；雨夜霓虹都市 $\to$ Cyberpunk / Cassette Futurism；乐观千禧生态未来 $\to$ Frutiger Aero / Solarpunk / Space-Age 等）。
2. **情绪亮度与光影基调**：它天生应该是明亮通透的晴空日光、温柔暖金黄昏，还是克制沉静的阴天/夜色？**光影情绪必须服从主题本身的感情基调**，绝不盲目套用阴郁灰暗或过度戏剧化的模板。
3. **世界观原生空间与道具**：只从这个世界观内部挑选自然成立的建筑结构、材质与细节（例如极简庭院用柱廊、石阶、水面投影；生态乌托邦用流线曲面、透光玻璃、水体与绿植），**禁止把其他流派的招牌零件或某张参考图的固定结构硬塞进来**。

- **跨题材解码思路示例（仅作思考示范，严禁照抄原词）**：
  - *静谧记忆/建筑诗意类意象* $\to$ 可发散为极简光影浅水庭院、被藤蔓爬满的古典石柱廊、或带有超现实漂浮器物的室内空间。
  - *温柔夜色/微风类意象* $\to$ 可发散为海边飘动薄纱的窗台、灯火映水的木栈道河岸、或亮着暖灯的屋顶花园。
  - *乐观未来类意象* $\to$ 围绕**光泽流线曲面、清透水体与蓝绿玻璃折射、明朗晴空与生机绿植**的抽象设计语法发散，可落点为滨海白色流线长廊与浅水步道、半嵌入草坡或水下的透明球穹、高架轨交绿植露台、水面折射透光球体与阳光广场、或奶油白配珊瑚橙的悬挑观景台等多元构图，而不应滑向灰暗废墟或重工业机械，也不要每次都千篇一律画成带水池的玻璃大厅。

## 三、按画风自适应的层次丰富度（不靠硬塞固定部件凑数）

为了让任何画风都不显得像“空地上摆了两个裸方块”，构思和编写代码时都应照顾**主次结构 + 环境细节**的层次感，但**具体放什么细节必须由当前画风决定**：

| 复杂度梯队 (`complexity_tier`) | 适用场景类型 | 净内容单元门禁与推荐 | 符合画风的细节组织方式 |
| :--- | :--- | :--- | :--- |
| **`tier1_intimate`** | 室内特写、窗台静物、极简构成、微缩模型 | 门禁 `>= 18`，推荐 `45~100+` | 精细拆分主角部件（倒角/厚度/结构衔接）+ 2~3 组桌台/地面配套 CC0 小道具 + 柔和光线投影层次。 |
| **`tier2_architectural`** | 室内大厅、街巷拱廊、园林庭院、水景广场、现代公共空间 | 门禁 `>= 32`，推荐 `80~180+` | 原创主空间结构 + 两侧走廊/夹层/植栽群落 + 建筑细部（门窗棂格/栏杆/阶梯/灯饰）+ CC0 植物、器皿或地表散布细节。 |
| **`tier3_spectacular`** | 开阔自然地景、宏大生态都市、大型天际线、巨构奇观 | 门禁 `>= 60`，推荐 `150~320+` | 前景高质感锚点（植物/水岸/栈桥）+ 中景主建筑群 + 远景天际线与空气透视天空（晴空或云雾按主题选用）。 |

## 四、双模式提问语感对照（自然流畅，拒绝四字词电报体）

- **简易模式（大白话，零术语，不超过 14 字）**：
  - `长满青苔的安静石拱门`
  - `飘着白纱帘的海边小窗台`
  - `走不到头的死循环怪楼梯`
  - `晴天水波亮晶晶的海滨白廊`
- **详细模式（顺畅自然的长短句 + 单个核心括号说明）**：
  - `午后阳光斜穿过半开放的灰白石柱长廊，在浅浅的静水倒影里拉出清晰的明暗节奏（现代极简光影建筑）`
  - `透过微风吹起的浅蓝薄纱望向窗台上的玻璃水杯，窗外是干净明亮的夏日海平线（清透二次元框景）`
  - `雨后的窄巷地面映出暖橙和青色招牌的反光，高架铁桥从头顶斜穿过去（赛博雨夜街景）`
  - `用正交镜头对准四段首尾相连的悬空阶梯，在特定角度下严丝合缝咬合成死循环（非欧彭罗斯视错觉）`
  - `晴朗积云下延伸着一条洁白流线型的海滨生态步道，半嵌入草坡的透光球穹旁分布着浅水渠与植物群落（千禧生态未来海滨长廊）`
