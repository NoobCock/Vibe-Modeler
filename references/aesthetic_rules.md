# 画面风格与材质参考

建模和渲染时，不要把画风混为单一的“写实”或“卡通”，而是从形状、材质和光线三方面分别设定。

---

## 一、风格的三项拆分

1. **形状外观**：
   - 抽象几何：方块、长条柱体、薄板切面。
   - 低多边形（Low-Poly）：清晰可见的三角面和多边形切角，不开平滑。
   - 现代建筑：平顶、大挑檐、落地窗、大块地砖。
   - 场景景物：道路、小船、台阶、护栏、树木。
2. **材质表面**：
   - 物理 PBR 真实质感：微水泥粗糙度起伏、金属拉丝、磨砂玻璃折射、剥落锈迹。
   - 哑光石膏黏土：纯色高粗糙度无高光，靠阴影出体积。
   - 纯平切面（Flat）：纯色面片，不开光滑着色。
   - 赛璐珞二次元：明确的双阶色块过渡与描边。
3. **光线氛围**：
   - 晴空日光：45度侧光，阴影清晰，天光微蓝。
   - 暮色暖金：低角度金橙色主光，长阴影。
   - 影棚柔光：大面积柔光箱，阴影极软。
   - 暗调冷光：深色底色，靠局部发光和边缘高光勾出轮廓。

## 二、常见画风搭配参考

### 1. 暗调科技抽象（金属与玻璃）
- 形状：半空悬浮的长方体、棱柱。
- 材质：高透磨砂玻璃（粗糙度 0.1，IOR 1.52）、拉丝金属（金属度 1.0，带微划痕）、橙色自发光小块。
- 色调：纯黑背景 + 银灰金属 + 局部电光橙。

### 2. 超现实极简建筑（石膏与黏土）
- 形状：单点透视长廊、连续拱门、极简台阶、圆球。
- 材质：哑光石膏粉墙（粗糙度 0.9，无明显反光）、浅色原木。
- 色调：蜜桃粉配奶白，或纯白配浅水泥灰与淡蓝窗洞。

### 3. 低多边形风光（Low-Poly）
- 形状：多边形切面山体、台阶状峡谷、低模树木。
- 材质：开启纯平着色（Flat Shading），水面保留高光反射。
- 色调：砖红陶土色岩石对冲蓝绿水面，加一轮淡黄落日。

### 4. 日系动漫写实风（带岁月感的场景）
- 形状：淹水的公路、老旧小船、防波堤、带杂草的栏杆。
- 材质：带做旧细节的 PBR（剥落白漆、局部铁锈斑、混凝土微孔、水面反光）。
- 色调：清澈蔚蓝天空与海水，翠绿植物，暖橙锈斑点缀。

### 5. 极简滨海建筑
- 形状：平顶大挑檐水泥屋、落地大玻璃、整齐砂岩地砖、沙坑多肉。
- 材质：微粗糙清水混凝土、砂石铺地、双面反射玻璃。
- 色调：砂石米黄 + 水泥中灰 + 海水蓝。
