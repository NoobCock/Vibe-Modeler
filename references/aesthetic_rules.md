# Vibe-Modeler 场景美学与五大经典视觉风格体系

本手册提炼自成熟唯美 3D 渲染作品（涵盖极简抽象、超现实建筑、低多边形风光、日系二次元写实背景与现代建筑），为各 Subagent 提供清晰的几何、材质与布光配方，杜绝模型理解趋同与塑料感。

---

## 一、三维解耦美术体系（核心原则）

画风严禁粗暴定为“写实”或“卡通”，必须正交拆分为三个独立维度：

| 维度 | 选项范围 | 典型视觉特征 |
| :--- | :--- | :--- |
| **1. 几何形态（Form）** | 抽象几何物块 / 低多边形（Low-Poly） / 现代极简构筑 / 故事场景景物 | 决定模型的布线方式与外轮廓（倒角硬边、纯平面切面、或结构化建筑） |
| **2. 材质质感（Shading）** | PBR物理微质感 / 哑光石膏黏土 / 赛璐珞色阶 / 纯平Flat着色 | 决定光线与物体表面的微观反应（粗糙度噪波、折射色散、色块阶梯） |
| **3. 光影意境（Lighting）** | 晴空日光 / 暮色暖金 / 影棚柔光 / 暗调荧光 / 阴雨漫射 | 决定画面整体的明暗开合、冷暖反差与阴影硬度 |

---

## 二、五大经典视觉风格体系详解

### 1. 暗调科技抽象与金属玻璃（Dark Tech Abstract）
- **形体特征**：半空交错悬浮的立方体、长条棱柱、微倒角几何薄板。
- **材质配方**：
  - 高透磨砂玻璃（Transmission 1.0, Roughness 0.08~0.15, IOR 1.52，边缘微色散）。
  - 阳极氧化/拉丝金属（Metallic 0.95, Roughness 0.18，微细条纹噪波驱动法线）。
  - 电光自发光核（Emission 强度 5~15，作为视觉视觉焦点）。
- **光影与色板**：纯黑深邃背景（#0A0A0A）+ 银灰冷光高光 + 局域电光暖橙（#FF5500）强调色。

### 2. 超现实建筑极简与黏土石膏（Surrealist Architecture & Clay）
- **形体特征**：单点透视无限延伸的长廊、连续拱门切口、微缩阶梯、极简几何柱体、大量平整负空间。
- **材质配方**：
  - 纯净哑光石膏/黏土（Base Color 单色，Roughness 0.85~0.95，无任何高光，轻微微噪波 Bump 模拟墙面触感）。
  - 浅色温润原木（微弱木纹起伏，无反光漆面）。
- **光影与色板**：单向定向硬日照 + 柔和环境漫射遮挡（AO），投射出清晰干净的几何斜长阴影。
  - 色系 A（马卡龙柔暖）：蜜桃粉 + 奶白 + 浅粉紫地表。
  - 色系 B（素雅白灰）：纯白墙面 + 微水泥浅灰 + 极淡的天空蓝窗洞。

### 3. 低多边形唯美风光（Low-Poly Polygonal Landscapes）
- **形体特征**：网格表面开启 Flat Shading（纯平面无平滑着色），岩石、山体、水面全部由清晰可见的多边形面片构成。
- **材质配方**：色块纯平材质（Principled BSDF，Roughness 0.6~0.8，Flat 切面驱动光暗转折），水面保留适度 Specular 高光以反射光带。
- **光影与色板**：巨大而清晰的轮廓主光源（如地平线巨日）。
  - 经典互补色：暖赭红/陶土珊瑚橙岩体 vs 蓝绿色翡翠水体，冷暖对冲强烈而通透。

### 4. 日系动漫写实背景美术（Anime Realistic Background Art）
- **形体特征**：带有岁月痕迹的真实世界景物（沿海公路、防波堤、带吊杆的小工作船、长满杂草的废墟护栏）。
- **材质配方**：**二次元形态 + PBR 做旧质感**：
  - 混凝土与白漆表面带有局部杂色噪波（Noise 作为遮罩，在白漆与剥落深色底色之间渐变）。
  - 钢铁边缘带有小面积铁锈与污渍（Rust Streaks）。
  - 地面积水利用玻璃/透明通道做局部高反光。
- **光影与色板**：高明度纯净晴空，深邃湛蓝海面 + 翠绿草丛树木 + 暖橙色锈蚀小色块点缀，光影通透、无死黑。

### 5. 当代极简滨海建筑写实（Modernist Coastal Architecture）
- **形体特征**：大挑檐水平悬挑平屋顶、超白落地大玻璃、整齐的大块砂石铺装地面、干燥沙坑配耐旱多肉/橄榄树。
- **材质配方**：物理级 PBR 清水混凝土（细微气孔噪波 Bump）、浅米色砂岩地砖、清澈双面反射玻璃。
- **光影与色板**：地中海烈日天光，微暖石材米黄 + 清冷混凝土灰 + 饱和海蓝色。
