# Vibe Modeler

> 让LLM给你出主意，从零开始用Blender建造个3D场景出来。

你**不太需要**掌握Blender的高阶使用技巧，也能用这个Skill建造出一个看起来挺屌挺像那么回事的场景。

## 快速开始

1. **在电脑上安装Blender**<br>
   Blender完全开源免费，你可以在 [Blender官网](https://www.blender.org/download/) 或者 [Steam](https://store.steampowered.com/app/365670/Blender/) 上直接下载并安装。<br>
   该项目推荐配合Blender **4.x** 或 **5.x** 使用。

2. **安装SKILL**<br>
   在这个Agent已经比我聪明的年代，我相信你可以直接从Release下载个压缩包扔给它，让它给你自动装上。<br>
   当然了，你也可以手动把该Skill安装到Agent的Skill目录中。

> [!NOTE]
> 我推荐你使用一些主流Harness使用该Skill，例如
>
> - **Claude Code**
> - **Codex**
> - **Antigravity**
> - **Grok Build**
>
> 这些Harness在开发此Skill时经过完整测试，至少能确保绝对的兼容性。

3. 直接跟LLM讲“`我要用Vibe Modeler建个3D场景`” 或者 “`用Vibe Modeler给我建个3D场景`”就好，只要是一个IQ大于67的LLM应该都能理解你要做什么，并会按照SKILL的指示向你逐步提问，完成建模。

> [!WARNING]
> 建议你使用多模态能力以及智商都相对较强的LLM配合此SKILL，否则最终结果将会惨不忍睹。<br>
> 在测试时，**Gemini** 和 **Claude** 的出图效果相比于其它模型大幅领先。

## 项目特点

### 你真的不需要掌握Blender的高阶使用技巧
如果你没有进一步编辑工程的需求，那么你只需要知道怎么旋转、移动、缩放视图就好了，LLM会自行完成 `创建工程` `构思场景` `寻找资产` `建模` `搭建场景` `渲染出图` 的完整过程

### AI和你对话有一个循序渐进的过程
不同于你在网上看到的所有AI建模装逼视频，这个Skill建造场景的过程**并不是纯粹许愿性的**。<br>
LLM能够给你几个意象作为参考，也可以让你自行表达你想到的画面需求，在你完成初步构思之后，LLM会逐步向你提问场景的各项细节，**最终基本确认你的想法和场景搭建的计划吻合之后才会正式开始工作**。

### 你可以选择四种对话的语气
###### 其中有三种都挺像人话
我知道你已经被OpenAI发明的诡异高熵中文折磨的要死不活了，所以这个Skill内置了精简版的 [说人话](https://github.com/MrGeDiao/shuorenhua) Skill，并且向建模场景进行了特调。<br>
你可以选择 `热情` `冷静` `暴躁老哥` 以及人人都厌烦的 `纯正AI腔调` 和你对话，四种对话的语气里面三种都挺像人。

### 你可以给AI建模的结果打一星好评
###### 而且LLM会记住你的评价
你懂的，虽然这东西看上去很牛逼，LLM给你对于场景描述好像也很牛逼，但是最终出图的效果还是由LLM的智力水平和你的个人审美标准决定的，因此该Skill在每次渲染出图之后都会让LLM询问你对于图片风格、光影、构图等方面的评价，如果你不满意它就会**现改**，并且在此后**记住你每次评价的结果**。只要你出的图够多它就会慢慢理解你的偏好。

<br>

- 由于我本人的审美能力 [极其极其极其极其极其极其](https://cdn3.ldstatic.com/original/4X/a/2/c/a2ce023ca646fcc76d5a04b8e98d89ccb393d5db.png) 有限，本Skill场景构建的参考图可能**并不涵盖所有艺术风格**，如果你在要求LLM渲染某些风格的场景时遇到了不满意的效果，欢迎向我提交Issue，最好提供你预期中效果的**参考图**（可以是使用生图模型生成的），我会积极采纳并持续完善。
<br>

- 由于例如GPT一类的贱逼防御性模型在指令遵循方面的水平堪比一块发芽的土豆，所以你在要求其使用Skill时可能会出现它**不愿意按照流程工作**的问题，如果你遇到了这方面的错误，欢迎向我提交Issue。
<br>

- 当前阶段的Skill**没有教LLM怎么建人体**，也没有给它任何参考，如果你尝试在场景中添加或要求其建造人物模型可能导致最终出产的结果一团糟。我理解一个场景图当然也可以拥有一些人物模型，但是鉴于我自己也不会建模一个看起来像人的人体模型，所以这方面的功能我还没有考虑好要不要真的加入进去。
